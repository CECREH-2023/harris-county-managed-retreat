# Scenario definitions

The current [Scenario_Parameters.csv](Scenario_Parameters.csv) contains 24 settings across four illustrative policy families. It records values, units, time bounds, triggers, evidence status, and rationale. These are proposed experiments for 2025–2050; they have not been executed or calibrated.

The earlier scenario catalog, baseline YAML, and override template are retained as design examples. Their labels and example values are not replacements for the current Harris County configuration. Reconcile all settings and a common initial-condition profile with the executable Vensim model before comparison. Record the exact model version, parameter version, random seeds if used, and outcome definitions with any future run.
