# Reproducing and validating this release

The included checks require Python 3.10 or newer and only the Python standard library. The Excel workbook can be opened in spreadsheet software; it is a data dictionary, not a simulation workbook. No network access, external packages, credentials, or Vensim installation is required for these checks.

From the repository root:

```bash
python3 scripts/check_release.py
python3 scripts/check_package.py
python3 scripts/export_dictionary.py
```

`check_release.py` verifies the 300-entry inventory, coverage of the 295 source-assessment entries, dependency endpoints, parameter/scenario/stock references, missing-value and assumption counts, geographic keys, and five selected Census/ACS derivations. It checks workbook ZIP integrity and confirms that all dictionary variables appear in the saved workbook. It does not validate every source record, every equation, or the original parcel overlay.

`check_package.py` compares every distributed file with `MANIFEST.sha256` and reports unexpected files. It checks distribution integrity; it does not execute a model. Files generated by the export command are intentionally excluded from the manifest under `results/generated/`.

`export_dictionary.py` produces a standalone, searchable HTML dictionary at `results/generated/Model_Data_Dictionary.html` from the distributed CSV. The CSV and Excel workbook are preserved snapshots; their original editorial creation required retained collaborator and source material. No promise of a byte-identical rebuild of the styled workbook or the full raw-data pipeline is made.

## Rebuilding upstream inputs

Use the variable dictionary's required fields and derivation notes, the parameter-to-source map, and the source catalog to obtain equivalent evidence under the providers' terms. Reconstruct the documented geography, period, reporting universe, and units before comparing values. The raw/intermediate research inputs and full acquisition pipeline remain outside this release. Existing source hashes support identification but do not substitute for access to omitted records.

## Integrating with Vensim

Obtain `models/Managed_Retreat_Main.mdl` from the model team; verify the edition and import functionality. Reconcile the current dictionary, proposed equation repairs, parameter names, initial conditions, and scenario settings with the executable model. Resolve missing measurements or explicitly label scenario assumptions. Then perform dimensional, accounting, numerical, calibration, and sensitivity checks described in the [development status](DEVELOPMENT_STATUS.md). Merely supplying a file at that path does not establish model validity.
