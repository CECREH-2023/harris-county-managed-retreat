# Software

Python 3.10+ runs the included release checks and dictionary HTML export using only the standard library. Spreadsheet software is optional for viewing the Excel dictionary. Vensim is the intended simulation platform; no executable model, runtime, license, tested edition, or simulation output is bundled.

The original evidence preparation used additional data and geospatial libraries. Those upstream computations are outside this release's self-contained validation boundary. A working simulation environment must be documented when the executable model becomes available.
