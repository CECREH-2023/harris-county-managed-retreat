# Code and document map

| File | Role |
| --- | --- |
| `scripts/check_release.py` | Checks current dictionary, configuration, table keys, and selected derivations |
| `scripts/check_package.py` | Checks distributed file hashes and package membership |
| `scripts/check_inputs.py` | Reads the input-presence specification; presence alone is not validation |
| `scripts/export_dictionary.py` | Exports the current CSV to a standalone searchable HTML view |
| `config/model_boundary.json` | Case, period, units, proposed numerical settings, and unavailable model status |
| `documentation/Model_Data_Dictionary.csv` | Current 300-entry editorial definition and derivation snapshot |
| `docs/MODEL_DESIGN.md` | Earlier guide architecture, retained for design provenance |

The original research workspace's download, spatial preparation, and workbook-authoring scripts depend on retained source files and local project material. They are outside this curated release. See [reproduction boundaries](REPRODUCING.md) before interpreting package checks.
